# 03 · NPU Field Devices

[← Profile](../README.md)

**요구사항 → 디바이스 구성 → 검증 → 인계**

국산 NPU 실증과제의 디바이스 담당자로서, 장비 구성과 적용 버전,
문제 해결 과정, 검증·인계 근거를 연결해 관리하는 것을 목표로 합니다.

## Focus

- 디바이스 담당 범위와 과제 요구사항 정리.
- 적용한 보드·OS·NPU 구동환경의 구성 추적.
- 직접 수행한 작업과 협업·지원 범위 구분.
- 이슈 처리, 검증 결과, 납품·인계 자료 연결.

## Evidence to keep

| Record | Purpose |
|---|---|
| 요구사항과 담당 범위 | 어떤 결과를 책임졌는지 설명 |
| 장비 구성과 적용 버전 | 실제 현장에 사용한 구성을 식별 |
| 이슈와 확인 근거 | 해결한 문제와 남은 제약을 추적 |
| 인계·완료 확인 | 다음 담당자가 이어갈 수 있도록 정리 |
