# 01 · RK3588 Linux Platform

[← Profile](../README.md)

**OS 구성 → Board bring-up → 이미지 검증 → 배포**

RK3588 SoC를 활용한 임베디드 Linux 보드를 대상으로, 필요한 OS 구성과
하드웨어 동작을 연결하고 재현 가능한 배포 절차를 만드는 것을 목표로 합니다.

## Focus

- 보드에 맞는 OS 구성과 빌드 입력 정리.
- 부팅·주변장치 문제의 재현, 원인 분석과 변경 근거 기록.
- 배포 이미지의 버전·구성·검증 결과 연결.
- 설치 방법과 알려진 제한 사항 정리.

## 01.2 · OS Imager

보드용 이미지를 사용자가 설치할 수 있도록 배포 이미저를 개발합니다.
지원 대상 식별, 이미지 선택, 기록, 결과 확인과 실패 안내를 하나의 사용 흐름으로 연결합니다.

## Evidence to keep

| Record | Purpose |
|---|---|
| 보드와 이미지 구성 | 어떤 대상으로 만든 배포물인지 확인 |
| 수정 사항과 분석 근거 | 변경 이유와 본인 기여를 설명 |
| 설치·검증 기록 | 해당 버전의 확인 범위와 제한을 명시 |
| 재현·복구 절차 | 다음 설치와 문제 대응에 재사용 |

이 페이지는 개발 방향을 소개합니다. 개별 빌드와 보드의 검증 완료 여부는 해당 프로젝트 기록을 기준으로 관리합니다.
