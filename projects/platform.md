# RK3588 Linux Platform

[← Profile](../README.md)

RK3588 기반 보드를 위한 임베디드 Linux OS 구성과 배포.

- 보드 bring-up, 커널·Device Tree 수정
- OS 이미지 구성과 초기 설정
- 주변장치·NPU 구동환경 통합
- 이미지 제작, 무결성 검사, 배포

## OS Imager

보드용 OS를 선택하고 SD 카드에 설치하는 Windows 프로그램.

- Qt/QML 설치 화면과 한국어 UI
- 이미지 카탈로그와 다운로드·기록 흐름
- 배포 이미지 크기·SHA-256 검사
