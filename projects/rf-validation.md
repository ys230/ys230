# 02 · RF Test & Validation

[← Profile](../README.md)

**시험 제어 GUI → 실제 RF 측정 → KC 인증 대응**

AP6354 / AP6398S의 시험 제어와 스펙트럼 애널라이저 측정 과정을 연결해,
어떤 설정에서 어떤 동작이 확인됐는지 추적할 수 있도록 정리하는 것을 목표로 합니다.

## Focus

- 모듈별로 확인된 시험 제어 기능을 GUI로 구성.
- 명령 전달 결과와 실제 측정 결과를 각각 기록.
- 시험에 사용한 장치·소프트웨어 구성과 계측 조건 정리.
- 사전 검증, 시험기관 대응, 최종 적합성평가 결과를 연결.

## Evidence to keep

| Record | Purpose |
|---|---|
| 모듈별 지원 범위 | 구현된 기능과 미확인 기능 구분 |
| 제어·응답 기록 | 시험 설정과 장치 상태 추적 |
| 측정 조건·결과 | 동일 조건으로 확인할 수 있는 근거 |
| 인증 대응 내역 | 실제 담당 업무와 공식 결과 연결 |

이 페이지는 개발 목표를 소개합니다. 특정 모듈의 RF 검증이나 KC 인증 완료를 주장하지 않습니다.
